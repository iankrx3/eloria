# 디자인

Eloria의 화면은 "새벽빛 라벤더"(밝은 화면)와 "노을 진 창가"(플레이어)의 두 분위기로 나뉜다. 기준은 지원서의 초기 UI 시안(홈, 플레이어, 온보딩 퀴즈) 3장이며, 아래 색상 값은 시안에서 추정한 시작값이다. 디자이너가 확정하면 이 문서와 `apps/mobile/src/theme/`을 함께 바꾼다.

## 1. 브랜드

- 이름: Eloria / 태그라인: "A BRIGHTER YOU AWAITS" / 슬로건: "상상에서, 글로, 마침내 현실로."
- 로고: 세리프 워드마크 "Eloria" + 작은 대문자 태그라인. 홈 상단의 빛나는 오브(달 모양 초승달이 든 구)가 브랜드 심볼.
- 성격: 몽환적이지만 과장되지 않음, 다정함, 여유.

## 2. 토큰 (NativeWind 테마)

| 토큰 | 값(시작값) | 용도 |
| --- | --- | --- |
| `bg-dawn` | #F3ECF6 | 밝은 화면 배경(라벤더 그라디언트 시작) |
| `bg-dawn-2` | #EADDF0 | 그라디언트 끝, 카드 뒤 |
| `surface` | #FFFFFF, 불투명도 70% | 입력창·카드(유리 느낌) |
| `plum` | #6E4A7E | 주 강조(전송 버튼, 활성 탭) |
| `plum-deep` | #3E2A47 | 제목 텍스트 |
| `ink-muted` | #8C7B94 | 보조 텍스트 |
| `rose` | #C9A0AE | 퀴즈 배경 톤, 선택지 테두리 |
| `dusk` | #2B1E1A | 플레이어 배경 오버레이(이미지 위 60% 불투명) |
| `glow` | #F6D9B8 | 플레이어 하이라이트, 진행 바 |
| `on-dusk` | #FFFFFF | 플레이어 위 텍스트 |
| `kakao`, `kakao-label` | #FEE500, 검정 85% | 카카오 로그인 버튼 전용(카카오 디자인 가이드 고정값, 라운드 `kakao` 12) |

- 라운드: 카드 20, 입력창·선택지 16, 버튼 원형 또는 999.
- 간격: 4의 배수(4, 8, 12, 16, 24, 32). 화면 좌우 여백 20.
- 그라디언트는 배경에만 쓰고 버튼·텍스트에는 쓰지 않는다.

## 3. 타이포그래피

| 역할 | 폰트 | 크기/행간 |
| --- | --- | --- |
| 워드마크·큰 제목·플레이어 자막 | Noto Serif KR(Medium) | 28/38, 자막 26/36 |

## 4. 핵심 화면 명세

**홈**
- 상단: 워드마크, 오른쪽에 연속 청취(스트릭) 칩.
- 중앙: 오브 → "오늘, 어떤 미래를 그려볼까요?" → 보조 문구 "상상에서, 글로, 마침내 현실로."
- 입력창: placeholder "원하는 삶을 자유롭게 적어보세요…", 오른쪽 원형 plum 전송 버튼.
- 오늘의 순간 카드(데일리) 한 장.
- "당신을 위한 제안" 가로 카드 4종: 경제적 자유 / 사랑하는 관계 / 커리어 & 성공 / 건강한 나. 오른쪽에 "목표 수정하기".

**플레이어**
- 전체화면 표지 이미지 + `dusk` 오버레이. 상단: 닫기, 워드마크, 설정(보이스·배경 사운드).
- 현재 문단을 큰 세리프 자막으로 표시(예: "로비에 도착하기도 전에, 이미 손안이 따뜻해집니다.").
- "전체 스토리 보기" 칩, 반복 토글.
- 진행 바(경과/남은 시간), 컨트롤: 좋아요 · 10초 되감기 · 재생/일시정지(흰 원) · 10초 앞으로 · 배경 사운드.
- 하단 "공유하기".

**온보딩 퀴즈**
- 배경: 따뜻한 로즈 톤 사진 + 오버레이, 상단 진행 바와 "n / 12".
- 큰 세리프 질문(예: "지금, 당신의 연애 상태는 어떤가요?") + 보조 문구.
- 선택지: 반투명 카드 리스트, 오른쪽 화살표. 탭하면 바로 다음 문항.

**생성 진행**
- 오브가 천천히 호흡하는 애니메이션(`react-native-reanimated`), 단계 문구 교체, 텍스트 도착 시 "먼저 읽어보기" 버튼.

## 5. 모션·접근성

- 전환은 페이드·살짝 위로(200~300ms). 반복 애니메이션은 오브 하나만.
- "동작 줄이기" 설정이 켜져 있으면 오브 애니메이션을 끈다.
- 텍스트 대비 WCAG AA(밝은 화면 본문 4.5:1 이상). 플레이어 자막은 오버레이 위에서 확인.
- 모든 아이콘 버튼에 `accessibilityLabel`(한국어). Dynamic Type 확대 시 레이아웃이 깨지지 않게 한다.

## 6. 카피 톤

- 존댓말, 짧은 문장, 이모지 없음.
- 결과를 약속하지 않는다: "이루어집니다" 대신 "그려 보세요", "오늘도 그 하루를 살아 봐요".
- 오류 문구도 다정하게: "미래를 그리는 데 조금 더 시간이 필요해요. 잠시 후 다시 시도해 주세요."
