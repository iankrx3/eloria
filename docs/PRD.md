# PRD — Eloria

> "상상에서, 글로, 마침내 현실로." 막연한 꿈 한 줄을 나만의 가장 선명한 미래로 그려 주는 앱.

## 1. 문제와 가설

- 끌어당김·확언·369·비전보드 콘텐츠는 많이 소비되지만, 기존 앱(목표 → 확언 → 비전보드 → 기록 → 습관)은 사용자가 **스스로 상상해야** 해서 지속되지 않는다.
- Eloria의 흐름은 **꿈 입력 → AI 개인화 → 미래의 하루 생성 → AI 음성 재생 → 매일 반복**이다. 사용자는 상상하는 대신 듣는다.
- 핵심 가설: 개인화된 미래 스토리를 음성으로 들으면 **다음 날에도 다시 듣는다**. MVP는 이 재방문 방정식을 먼저 검증한다.

## 2. 대상 사용자

- 20~30대 한국 여성, 끌어당김·자기계발·라이프스타일 숏폼(TikTok·Instagram·Threads)을 소비하는 사람.
- 원하는 것은 "람보르기니" 같은 목표 한 줄이 아니라, 그 삶을 사는 **감정과 일상**이다(한강뷰 아침, 사랑하는 사람과의 저녁, 일에서의 자신감).

## 3. 핵심 루프

```text
Intro Quiz → Manifest(꿈 한 줄) → Listen(미래 스토리) → Daily Ritual(데일리·확언) → 다시 Manifest
```

우선순위: P0 = 출시 필수(5주차 검증 범위), P1 = 출시 직후 Stella 기능 동등화, P2 = 차별화.

## 5. Intro Quiz 문항(초안)

Stella는 26~28단계로 이탈이 크다는 분석이 있어 10~12문항으로 시작한다. 문항과 선택지는 `packages/shared/src/quiz.ts`에 데이터로 둔다.

1. 어떻게 불러 드릴까요? (이름, 텍스트)
2. 지금 가장 바라는 삶은? (경제적 자유 · 사랑하는 관계 · 커리어 & 성공 · 건강한 나 · 자신감, 복수 선택)
3. 지금, 당신의 연애 상태는 어떤가요? (싱글이에요 · 연애 중이에요 · 조금 복잡해요 · 결혼했어요)
4. 미래에 함께하고 싶은 사람이 있나요? (이름·관계, 선택 입력, 여러 명)
5. 꿈꾸는 하루는 어디서 시작되나요? (서울 도심 · 바닷가 · 해외 도시 · 조용한 자연)
6. 1년 뒤, 가장 달라져 있고 싶은 것은? (자유 입력)
7. 요즘 가장 자주 드는 감정은? (불안 · 지침 · 설렘 · 조급함 · 평온)
8. 미래의 나는 어떤 사람인가요? (여유로운 · 당당한 · 다정한 · 자유로운 · 성공한, 최대 3개)
9. 스토리 톤은? (차분하게 · 설레게 · 힘 있게)
10. 주로 언제 듣고 싶나요? (아침에 눈 뜨자마자 · 출퇴근길 · 잠들기 전) → 알림 시간 기본값
11. 목소리 취향 (미리듣기 3종 중 선택)
12. 알림 허용 요청(시스템 권한 프롬프트 전에 이유 설명 화면)

7번 감정 문항은 스토리 톤 조절에만 쓰고, 건강 관련 정보로 저장하거나 해석하지 않는다.

## 6. 화면 구성

하단 탭 4개(지원서 UI 시안 기준): **홈 · 라이브러리 · 리추얼 · 마이**.

| 화면 | 내용 |
| --- | --- |
| 온보딩 | 스플래시 → 퀴즈(진행 바) → 첫 꿈 입력 → 생성 진행 → 첫 스토리 → 계정 연결 → 페이월 (F-01·D-08: 연결은 페이월 직전) |
| 홈 | 인사 + "오늘, 어떤 미래를 그려볼까요?", 꿈 입력창, 오늘의 순간 카드, "당신을 위한 제안" 카테고리 카드 4종, 목표 수정하기 |
| 생성 진행 | 오브 애니메이션 + 단계 문구(미래를 그리는 중 → 목소리를 입히는 중), 텍스트 도착 시 "먼저 읽기" |
| 플레이어 | 전체화면 배경 이미지, 현재 문장 자막, 전체 스토리 보기, 컨트롤, 배경 사운드, 공유하기 |
| 라이브러리 | 내 스토리(꿈별 그룹), 플레이리스트, 좋아요, 다운로드됨 |
| 리추얼 | 카테고리별 사전 제작 콘텐츠, 확언 스와이프, 데일리 기록 |
| 마이 | 프로필(Personal), 나의 기록(이룸의 벽·감사일기·스트릭), 보이스·배경 사운드 기본값, 알림 시간, 구독 관리, 개인정보·계정 삭제 |

## 7. 수익 모델

- 단일 구독 "Eloria Subscription": Personal Story + AI Voice + Daily Manifestation + Affirmation + Ritual/Library.
- 가격 가설: 월 9,900원, 연간 할인 상품 1종(가격 미정, Q-01). 목표 월 9,900원 × 유료 10,000명.
- 무료: 퀴즈 + 첫 스토리 1개(재생 횟수 제한 여부 Q-03) + Library 일부 맛보기.
- 확장(출시 후): Premium Voice, AI Coach, Workshop → Community·B2B.

## 10. 카피 원칙

- 2인칭 현재형, 이미 이루어진 장면으로 말한다: "커튼을 열자 서울의 아침이 들어옵니다."
- 결과를 약속하지 않는다: "이루어집니다" 대신 "그려 보세요", "오늘도 그 하루를 살아 봐요".
- 존댓말 기본, 다정하지만 과장하지 않는다. 이모지는 쓰지 않는다.
