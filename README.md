# Eloria

> 상상에서, 글로, 마침내 현실로. — A BRIGHTER YOU AWAITS

막연한 꿈 한 줄을 "이미 그 삶을 사는 나"의 하루로 그려 AI 음성으로 매일 들려주는 manifestation 앱. O3C가 만든다.

- 앱: Expo(React Native), iOS·Android
- 백엔드: Supabase, Hono API, Inngest
- AI: Gemini(스토리), ElevenLabs(음성·이미지·효과음)
- 결제: RevenueCat
